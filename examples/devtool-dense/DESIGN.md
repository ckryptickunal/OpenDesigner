**Devtool Dense looks calm and compact, in a flat style.**
Designers: visual style: flat, tonal, glass · Code: `preset in state.json`

<details><summary>More</summary>

**Intent.** A dense, calm console for a fictional CI and observability tool: productive, compact, sharp, quiet.

- Audience: Engineers who keep it open all day on large desktop screens.
- The memorable thing: The run timeline: every step of a build on one line.
- Surfaces: Pipelines table (Operate: density compact; no hero; cards only to group related data); Run detail and logs (Read: density comfortable; no hero; `text.body.lg` for long text; no cards around running text)
- Platforms: web, desktop; inputs: pointer
- Direction: preset flat2 (the default until Q-dir-01 is answered)

**Principles (ranked).**
1. The task comes first: chrome recedes, data leads.
2. Dense, never cramped: visuals shrink, hit areas do not.
3. Quiet motion: show state changes, skip choreography.

**Dial positions.** Three posture dials set the overall stance. Five character dials fine-tune it.

- **Expression 20/100** (productive to expressive: productive): type ratio 1.2, hero moments: none, expressive motion: none, brand color role: reserved-accent, containment: whitespace.
- **Brand presence 55/100** (native to brand-led: balanced): typeface suggestion: open-custom-face, brand color placement: accent+signature-surface, native component share about 72%, voice guidance: short.
- **Density 85/100** (spacious to compact: compact): body 14px on the web, default control 32px, density mode compact, icons 16px; hit areas never shrink.
- **Energy 20/100** (calm to energetic: calm): standard easing [0.2, 0, 0.38, 0.9], duration multiplier 0.88, spring damping 1.0, heading weight 600, navigation: recessive.
- **Roundness 30/100** (sharp to soft: sharp): control radius 4, icon corners default, caps square.
- **Depth 22/100** (flat to deep: flat): depth model: ring+faint-shadow.
- **Colorfulness 30/100** (monochrome to vivid: monochrome): scheme neutral, accent chroma 18.0 (HCT), 1 accent(s), surfaces: neutral+one-accent.

## Do's and Don'ts

**These rules keep screens clear and easy to read.** The engine checks the ones it can.
Designers: guardrails and design linting · Code: `engine.py validate, engine.py review`

<details><summary>More</summary>

**Enforced by construction.** The generator cannot break these:
- text contrast 4.5:1, and 3:1 for edges, in every mode
- text on colored fills picked automatically
- tap areas pointer 24px
- a 2px focus ring with a 2px offset
- a reduced-motion mode
- inner spacing smaller than outer spacing, three text colors, and nested radii

**Do**
- Use semantic tokens; never raw hex, px or ms values in components.
- Keep one primary action per view and at most three type sizes per view.
- Pair every status color with an icon or label; underline links in running text.

**Don't**
- Don't shrink hit areas in dense layouts; shrink visuals and extend the hit area.
- Don't use motion as the only signal, or flash more than three times a second.
- Don't copy another brand's identity from a reference (colors, typeface, logo, imagery, copy).

**Current validation findings:** none (errors 0, warnings 0).

**Waivers:** none.

## Motion

> Zoom: broad (1 of 3), 1 decision in this area. To zoom in, answer Q-motion-01, Q-motion-02.
<!-- od:zoom area=motion level=1 -->

**Most movements take 220ms.** They turn into fades when a person asks for less motion.
Designers: motion system: duration, easing, springs · Code: `motion.duration.*, motion.easing.*`

<details><summary>More</summary>

**Intent.** Energy 20/100: durations x0.88 on medium and longer steps; standard easing `cubic-bezier(0.2, 0, 0.38, 0.9)`, enter `[0, 0, 0.38, 0.9]`, exit `[0.2, 0, 1, 0.9]`. Spatial spring: damping 1.0, stiffness 700.0 (Apple duration 0.237s, bounce 0.0; web `linear()` sample over 350ms).

| Token | Value |
|---|---|
| `motion.duration.instant` | 0ms |
| `motion.duration.micro` | 100ms |
| `motion.duration.short` | 150ms |
| `motion.duration.medium` | 220ms |
| `motion.duration.long` | 350ms |
| `motion.duration.extra` | 620ms |
| `motion.duration.medium-exit` | 160ms |
| `motion.duration.long-exit` | 260ms |

- Exits are about 25% shorter than entrances; linear easing only for spinners and progress.
- Reduced motion (`prefers-reduced-motion` or `data-motion="reduced"`): travel becomes opacity, feedback stays, `motion.transition.move` is 0ms.
- Springs are stored as damping and stiffness in `$extensions.opendesigner.spring` because DTCG 2025.10 has no spring type.
- Haptics: light intensity where the platform has them; sound: hook H-sound is pending.

Decisions: D-0015 (dials.energy).

## For Agents

**AI agents: read this file and the tokens before you change any screen.**

1. Before any visual work, read this file, PRODUCT.md and `tokens/` (start at `tokens/opendesigner.resolver.json`).
2. Use tokens, never raw values: CSS `var(--ds-...)`, Tailwind classes from `build/tailwind/theme.css`, `DS.*` in Swift, `DsTheme` in Compose.
3. Do not change a locked decision without asking the owner.
4. To change the system: `engine.py set <path> <value> --why "..."`, then `engine.py generate`, `engine.py validate`, `engine.py design-md`.
5. To extend: add a decision (never hand-edit tokens or this file). Keep semantic names the same across modes. Deprecate instead of deleting.
