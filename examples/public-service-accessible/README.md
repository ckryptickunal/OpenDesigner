# Public Service Accessible

![Public Service Accessible: components in light and dark, generated by the engine](preview.png)

A plain, high-contrast system for a fictional city benefits service: AAA text, generous targets, no motion.

**Dials:** expression 10 · brandPresence 85 · density 8 · energy 0 · roundness 0 · colorfulness 35 · depth 5 · warmth 45.

| What | Result |
|---|---|
| Type | body 19px, ratio 1.2, sizes 16, 19, 23, 27, 33, 39, 47; weights body 400, label 400, heading 600 |
| Space | 5px unit; default density spacious (controls 40/48/56px); hit areas pointer 48px, touch 48px |
| Shape | control radius 0, containers 0px, focus ring 3px |
| Depth | borders |
| Motion | medium 200ms, spring damping 1.0, motion off (reduced everywhere) |
| Color | neutral scheme, accent solid `#075c63`, text minimum 7.0:1, themes light |
| Validation | 0 errors, 0 warnings, 4 notes; 82 contrast pairs checked |

**Files:** `state.json` (the input), `decisions.md` (why each choice), `tokens/` (DTCG 2025.10 + resolver, canonical), `build/` (artifact, css, dtcg, figma, paper, tailwind), `DESIGN.md`, `PRODUCT.md`, `overview.html` (the whole system on one page), `preview.html` and `preview/` (the visual templates, filled in).

**Rebuild:** `python3 tools/build_examples.py public-service-accessible` runs `engine.py build` on `state.json` and rewrites this README. `python3 tools/build_examples.py --check` fails when a committed file differs from what the engine makes now.

The product is fictional; no real brand's identity is copied.
