# Color

## Overview

Replaces the 60-30-10 rule with four layers for product UI (neutrals, accent ramp, semantic colors, theming) and gives lightness targets for backgrounds, borders, buttons and text.

- [[sources/EcbgbKtOELY-every-ui-ux-concept-explained-in-under-10-minutes|Every UI/UX Concept Explained in Under 10 Minutes]]: Start from one primary brand color, lighten it for backgrounds and darken it for text, building toward a color ramp; use semantic colors with meaning and color for purpose, not decoration.
