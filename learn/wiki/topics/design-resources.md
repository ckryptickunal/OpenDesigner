# Design resources

## Overview

Names prompt sites (Good Brief, Sharpen Design) and inspiration sites (Dribbble, Pinterest, Instagram, Behance).

## Source Mentions

- [[sources/59XWYgN00nQ-create-a-portfolio-with-no-experience-or-clients-needed|Create A Portfolio With No Experience (or clients) Needed]]: Names prompt sites (Good Brief, Sharpen Design) and inspiration sites (Dribbble, Pinterest, Instagram, Behance).
- [[sources/66oOi9OLMCw-why-the-60-30-10-rule-is-ruining-your-ui-designs|Why the 60-30-10 Rule is RUINING Your UI Designs]]: Mentions UI colors for generating ramps and oklch.com for perceptually even chart hues.
- [[sources/6CC8lLnqa28-6-things-you-probably-need-to-hear-as-a-web-designer|6 Things You Probably Need to Hear (as a web designer)]]: Recommends online color pickers (the description links coolors.co) and Dribbble and Behance as sources of inspiration.
- [[sources/9WVt1CelBfg-the-stupid-simple-way-to-learn-ui-ux-design-in-exactly-10-minutes|The stupid simple way to learn UI/UX design in exactly 10 minutes]]: Mobbin, Dribbble and Pinterest are named as sources for a swipe file of hero and feature sections.
- [[sources/BvbFPzLjWcU-redesigning-a-modern-skincare-ui-from-scratch-free-design-files|Redesigning A Modern Skincare UI from SCRATCH (+ free design files)]]: Uses minimalmockups.com for product mockups and shares a free Figma file.
- [[sources/If7iCPDy2vk-the-7-ui-components-to-design-like-unicorn-ai-startups|The 7 UI Components to Design Like Unicorn AI Startups]]: The creator gives away Figma files of the components he built for each pattern.
- [[sources/adev-changelog-animations-dev|animations.dev]]: A 'Vault' of resources is updated regularly, and interviews with practitioners (Dennis Brotzky at Fey, Lochie Axon at Family) are part of the course.
- [[sources/c1TvOcKdBVE-the-8-ui-ux-cheat-codes-for-instantly-better-designs|The 8 UI/UX Cheat Codes for INSTANTLY Better Designs]]: Coolors for a starting base color and the Tailwind CSS color palette for ready-made accent and background pairs.
- [[sources/eeN7yUcIWbw-20-top-underrated-web-design-resources-for-2025|20 Top Underrated Web Design Resources for 2025]]: A list of 20 mostly free resources for UI elements, logos, fonts, inspiration, stock photos, 3D, icons, gradients, arrows, podcasts and portfolios.
- [[sources/ek-building-an-animation-course-building-an-animation-course|Building an animation course]]: Course bonuses include the Vault of curated articles, videos and personal websites, interviews with designers and engineers, and 18 custom easings.
- [[sources/eks-readme-emilkowalski-skills-readme-md|emilkowalski/skills: README.md]]: Index of the author's skills, with install command and newsletter.
- [[sources/gKM6b2EnW1k-upgrading-9-crucial-ui-elements-free-figma-file-included|Upgrading 9 CRUCIAL UI Elements (free figma file included)]]: All nine redesigned elements are offered as a free, editable Figma file.
- [[sources/pGYLZyBE32o-i-redesigned-google-s-ai-website-from-scratch-complete-transformation|I Redesigned Google's AI Website from SCRATCH (complete transformation)]]: Flaticon, filtered to interface icons, as a source of clean simple icons.
- [[sources/xHD01_Onac0-vibe-coding-a-pro-ui-in-seconds-with-ai|Vibe Coding a Pro UI in SECONDS With AI]]: Compares reference sources: busy Dribbble dashboards confuse the AI, SiteInspire and real products like Linear work better; 21st.dev supplies AI-ready components.
- See also: [[synthesis/design-resources|Design resources synthesis]]
- [[sources/YbLF42BaoZs-i-gave-claude-600-000-ui-screens-then-this-happened|I Gave Claude 600,000 UI Screens… Then This Happened]]: A library of over 600,000 real app and website screens, flows and animations, reachable from AI tools, used for research, quick lookups and competitor comparisons.
