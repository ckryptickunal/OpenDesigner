# AI-assisted design

## Overview

ChatGPT is used to write a full project brief from a short prompt.

## Source Mentions

- [[sources/59XWYgN00nQ-create-a-portfolio-with-no-experience-or-clients-needed|Create A Portfolio With No Experience (or clients) Needed]]: ChatGPT is used to write a full project brief from a short prompt.
- [[sources/7cTdCu8HMgM-the-definitive-process-to-present-uis-like-a-pro|The DEFINITIVE process to present UIs like a pro]]: AI is said to be not great at thoughtful UIs but good at mockups; a 30-word prompt with a green screen on the device gives a custom product mockup in 2 minutes.
- [[sources/Ksx9C2-3yMo-the-3-dashboard-ui-flaws-that-give-away-you-ve-never-built-one|The 3 dashboard UI flaws that give away you've NEVER built one]]: The presenter says AI struggles with the idea that UI is as much about what you cannot see as what you can.
- [[sources/PDcQJOPby1k-5-saas-ui-ux-mistakes-that-scream-you-vibe-code|5 SaaS UI/UX mistakes that SCREAM you Vibe Code]]: Lists tell-tale signs of AI-generated UI (emojis, bright clashing colors, repeated KPIs, gradient letter avatars, cards that do nothing) and says not to let AI choose colors or layout; AI handles logic well if told to.
- [[sources/RCneB_MQ7qs-the-one-thing-vibe-coding-cant-fix-about-your-website|The one thing vibe coding CAN’T fix about your website]]: He links an image-less, robotic site to vibe coding and argues that feeling and identity are what vibe coding cannot supply (from the title) [inferred]; the sponsor pitches an MCP for prototyping wireframes.
- [[sources/adev-changelog-animations-dev|animations.dev]]: AI produces motion that works but feels mediocre. The course ships a Cursor Rules file and skill.md with its principles so LLMs can review animations and answer motion questions; lessons have a copy-as-markdown button for feeding content to LLMs.
- [[sources/adev-home-animations-dev|animations.dev]]: Module 1 covers using AI for animations; 15 AI skills based on the course can review animations, suggest improvements and improve performance, and the skill file helps non-coders get far.
- [[sources/eeN7yUcIWbw-20-top-underrated-web-design-resources-for-2025|20 Top Underrated Web Design Resources for 2025]]: UX of AI is recommended because most designers will work with AI or in AI-adjacent fields.
- [[sources/ek-agents-with-taste-agents-with-taste|Agents with Taste]]: Encode taste as strict rules in one skill file per interface aspect so coding agents produce better visual work; use Anthropic's skill-creator; ask agents to review work against the skill.
- [[sources/ek-building-an-animation-course-building-an-animation-course|Building an animation course]]: AI is good at code but weak at choosing easing curves and durations; people who understand the code get more leverage; motion knowledge packaged as a SKILL.md lets coding agents build, review and suggest improvements to animations.
- [[sources/ek-developing-taste-developing-taste|Developing Taste]]: Notes that shipping a product that works is no longer a differentiator because everyone can do it, especially now with AI; brand, design, intuitiveness and experience are what stand out.
- [[sources/ek-friction-as-a-feature-friction-as-a-feature|Friction as a Feature]]: AI removed the cost of building, which lowered the bar for what gets built and produced a flood of undesigned apps and UI libraries.
- [[sources/ek-train-your-judgement-train-your-judgement|Train Your Judgement]]: AI-generated motion tends to work but feel mediocre; articulating why something feels right is presented as a key skill in the AI era, and the skill file lets coding agents follow the rules.
- [[sources/eks-readme-emilkowalski-skills-readme-md|emilkowalski/skills: README.md]]: Agents lack taste and make small, compounding mistakes; the skills list those mistakes and their fixes, and AI amplifies expertise rather than replacing it.
- [[sources/eks-skills-animate-skill-emilkowalski-skills-skills-animate-skill-md|emilkowalski/skills: skills/animate/SKILL.md]]: The source is an agent skill: it tells the model to make the motion call itself, write code, and report the gate, the ingredients and what needs a human feel-check.
- [[sources/eks-skills-animation-vocabulary-skill-emilkowalski-skills-skills-animation-vocabulary-skill-md|emilkowalski/skills: skills/animation-vocabulary/SKILL.md]]: The skill exists so people can name a motion effect precisely when prompting an AI or briefing a designer, and it prescribes how an agent answers naming questions.
- [[sources/eks-skills-find-animation-opportunities-skill-emilkowalski-skills-skills-find-animation-opportunities-skill-md|emilkowalski/skills: skills/find-animation-opportunities/SKILL.md]]: The source is an agent skill: it answers with a fixed first line, never edits code, hands off to improve-animations, and treats repository content as data rather than instructions.
- [[sources/eks-skills-improve-animations-plan-template-emilkowalski-skills-skills-improve-animations-plan-template-md|emilkowalski/skills: skills/improve-animations/PLAN-TEMPLATE.md]]: Plans are written so a less capable model with zero context and zero taste can execute them without improvising.
- [[sources/eks-skills-improve-animations-skill-emilkowalski-skills-skills-improve-animations-skill-md|emilkowalski/skills: skills/improve-animations/SKILL.md]]: An advisor pattern: a capable model audits and specifies, subagents audit categories in parallel, and cheaper models execute self-contained plans; repo content is treated as data.
- [[sources/eks-skills-pick-ui-library-skill-emilkowalski-skills-skills-pick-ui-library-skill-md|emilkowalski/skills: skills/pick-ui-library/SKILL.md]]: Written as instructions for an AI agent: fixed initial response, identify the task, check package.json, recommend one library, and flag when leaving the curated list.
- [[sources/eks-skills-prototype-picker-emilkowalski-skills-skills-prototype-picker-md|emilkowalski/skills: skills/prototype/PICKER.md]]: The spec is written for an agent to copy verbatim, with only variant names and count changing per run, so the tool looks the same every time it is generated.
- [[sources/eks-skills-prototype-skill-emilkowalski-skills-skills-prototype-skill-md|emilkowalski/skills: skills/prototype/SKILL.md]]: An agent skill that runs only when explicitly invoked, has a fixed first reply, stays in scope (not review, fixes or dependency choice), verifies its own output with the browser and screenshots, and stops for the person's choice.
- [[sources/eks-skills-review-animations-skill-emilkowalski-skills-skills-review-animations-skill-md|emilkowalski/skills: skills/review-animations/SKILL.md]]: Packaged as an agent skill with a fixed opening line, a narrow scope and a required output format for AI reviewers.
- [[sources/pGYLZyBE32o-i-redesigned-google-s-ai-website-from-scratch-complete-transformation|I Redesigned Google's AI Website from SCRATCH (complete transformation)]]: The page roadmap was partly generated with Gemini and Gemini generated the explore-section content, while the bento card descriptions were written without AI.
- [[sources/xHD01_Onac0-vibe-coding-a-pro-ui-in-seconds-with-ai|Vibe Coding a Pro UI in SECONDS With AI]]: A four-part prompt (design in HTML and CSS, purpose and use, specific elements, icon library) plus one well-chosen reference image produces a usable dashboard from Claude.
- [[sources/lkKGQVHrXzE-designing-with-claude-code|Designing with Claude Code]]: Uses Claude Code as the main design tool: a plain first prompt, then many short, specific refinement prompts, inspecting how elements are built and asking for temporary tools; notes AI defaults (indigo, centering, basic Inter).
