# 7 ui design trends that are CRIMINALLY slept on (don’t miss these)

## Metadata

- Video ID: `EHwZzWd-OnQ`
- Channel: Kole Jain
- Published: 2024-12-21T00:12:16Z
- URL: https://www.youtube.com/watch?v=EHwZzWd-OnQ

## Summary

Kole Jain walks through seven website design trends he considers underused at the end of 2024, as an alternative to the bento layouts and 3D animations he sees everywhere: text swapping, hand-drawn UI marks, text treated as a visual element, line dividers, morphing images or videos, animated diagrams, and images inside navigation menus. Each trend is shown on real sites, with a short note on what makes it work, such as the contrast between crisp bold text and loose hand-drawn marks, or rounded edges on dividers. He adds a few practical warnings: check font licenses, don't use lines on everything instead of spacing, and keep morphing-image changes small so the animation doesn't stutter. For a design system, the video is a menu of expressive options for landing pages and marketing sites, each of which could be offered to a person as a visual choice rather than a default.

## Key Ideas

- Bento layouts and 3D animations are everywhere in 2024 websites; less common effects make a site feel more original.
- Text swapping shows two matching pieces of text in one spot, which makes a simple, text-only page feel interactive with little work.
- Hand-drawn circles, underlines and arrows over crisp, bold text create a striking contrast.
- Text can be a visual element that tells a story, not only paragraphs, especially with a distinctive font or animation.
- Fonts taken from other websites need their licenses checked before use.
- Line dividers are coming back, but lines on everything instead of spacing feel like old PowerPoint slides.
- Dividers don't have to be straight lines everywhere; rounded edges can work well.
- Morphing images or videos can spice up weak media and make an entrance or a reel more striking, but massive image changes can slow the browser and make the animation choppy.
- Animated diagrams can explain a multi-step process as the visitor scrolls, or respond to hover in a simpler version.
- Images in a navigation menu help visitors tell products apart when the product names don't explain themselves.
- Even photos that aren't specific to menu items make a dropdown menu more engaging than plain text.

### Rules and practices

- **consider** (motion, web): On a text-led landing page, consider swapping a line of text for a matching alternative in the same spot as the visitor scrolls. Why: It shows two matching kinds of text in one spot and makes a simple page interactive without much work. [really cool way to have two matching kinds of text in one spot]
- **consider** (patterns, all): When adding hand-drawn circles, underlines or arrows, set the surrounding text in crisp, bold type so the loose marks contrast with it. Why: The contrast between perfect bold cut text and hand-drawn, slightly blurred handwriting is what makes the effect catch the eye. [the contrast between this perfect bold cut text and then the handdrawn]
- **must** (typography, all): Check a font's license before using a font file found on another website. Why: The source warns that without care over the licenses you will be a real criminal, not just joking about copying. [you do need to be a little bit careful about the licenses]
- **consider** (typography, all): Treat text as a visual element with a distinctive font or animation, instead of relying only on plain paragraphs. Why: Text can become an element that tells a story; distinctive and animated fonts are a strong way to do this. [your text doesn't just need to be boring paragraphs]
- **should** (layout, all): Don't put lines on everything as a substitute for spacing sections apart. Why: Lines everywhere recall old PowerPoint slides where people didn't realise they could just space things apart, and cramming content between lines looks dated. [when people didn't realize that they could just space things apart]
- **consider** (shape, all): If you use line dividers, consider giving them rounded edges rather than straight lines everywhere. Why: The source shows rounded-edge dividers working well on Isomorphic Labs. [you can add some rounded edges to them]
- **should** (motion, web): Make sure the changes in a morphing image aren't massive. Why: Massive changes can slow down the browser and make the animation seem choppy. [make sure the changes to your image aren't massive]
- **consider** (motion, web): Consider morphing an image or video when the media is weak on its own and needs spicing up. Why: The source presents morphing as a great way to spice up an image or video that is not strong enough alone. [you need to spice it up a little]
- **consider** (patterns, web): To explain a multi-step process, consider a diagram that reveals each step as the visitor scrolls, or a simpler diagram that animates in and reacts when each item is hovered. Why: Scroll-driven diagrams let visitors see the whole process in depth, and hover diagrams are a simpler but still interactive alternative. [as we scroll down we get to see the whole process in depth]
- **should** (components, web): When product names don't explain what the products are, show an image of each product in the navigation menu. Why: Visitors can tell products apart at a glance, as with Rivian's truck and SUV, like pictures on a restaurant menu. [they should do this on all websites or at least more of them]
- **consider** (components, web): Consider adding photos to dropdown menus even when they aren't tied to a specific item. Why: A menu that is only text is dull; photos add something to it. [when this menu comes down normally it's just text]

### Decisions it informs

- How should sections be separated: visible line dividers or space alone? (`Q-depth-05`)
  - Straight line dividers: Clear section boundaries; can feel rustic or modern depending on execution, but lines on everything look like old PowerPoint slides. When: When visible structure suits the style, as on the source's deliberately rustic cookie site or its modern cryptocurrency site.
  - Line dividers with rounded edges: Softer divisions that still mark sections, as on Isomorphic Labs. When: When straight lines feel too harsh for the rest of the style.
  - Space only: Sections separated by spacing, with no lines. When: When lines would crowd the layout; the source notes people once added lines because they didn't realise they could space things apart.
  - Recommendation: The source says line dividers are coming back and growing on him, but warns against using lines everywhere or jamming content between them.
- Should the page use hand-drawn marks (circles, underlines, arrows) over its text? (`Q-img-04`)
  - Hand-drawn marks over bold text: Loose, slightly blurred handwriting and arrows contrast with crisp, bold type; can carry a hover animation. When: For a simple landing page built mostly from text, since the source says it is easy to put together.
  - No hand-drawn marks: Clean text only. When: When the effect doesn't fit the brand [inferred].
  - Recommendation: The source calls hand-drawn effects a really cool effect that is easy to put together and growing on him, though he admits there is a little more to it than he describes.
- How should headline text behave on the page?
  - Plain paragraphs: Standard text blocks; the source calls repeated paragraphs boring. When: When content, not display, is the focus [inferred].
  - Distinctive display font as an element: Text becomes a visual element that tells a story. When: When the page can carry an expressive font [inferred], and only if the font's license allows the use.
  - Animated text: A distinctive font that animates out into other shapes or content. When: When the page wants a moment of motion built from type.
  - Text swapping: Two matching pieces of text alternate in one spot, often on scroll. When: For a simple, text-only page that should still feel interactive.
  - Recommendation: The source favours treating text as an element, with distinctive or animated fonts, rather than boring paragraphs.
- Should hero images or video reels morph as they enter?
  - Static media: Images and videos appear without shape changes. When: When the media is strong on its own or performance matters most [inferred].
  - Morphing media: The image or video changes shape as it enters or moves, and can slide into large text. When: When the image or video needs spicing up, or for a reel or portfolio entrance, making sure the changes aren't massive.
  - Recommendation: The source likes morphing entrances but says to keep image changes small so the browser doesn't slow down.
- How should a multi-step process or diagram be presented?
  - Static diagram: The full diagram is visible at once with no animation. When: When there is no time to build an animated version [inferred].
  - Scroll-driven animated diagram: Each step is revealed as the visitor scrolls, walking through the process in depth. When: When the team has the time and patience to build it; the source calls it very time-consuming.
  - Animate-in diagram with hover: The diagram animates in; hovering each item makes it rotate around and blur things out. When: When a simpler but still interactive version is enough.
  - Recommendation: The source calls the scroll-driven version among the most impressive effects but very time-consuming, and the hover version a simpler, still interactive option.
- Should the navigation menu include images?
  - Text only: A plain list of names; the source calls this no fun. When: When names are self-explanatory [inferred].
  - Product images per item: Each item shows a picture of the product, so visitors can tell them apart at a glance. When: When product names don't explain what they are, as with Rivian's R1T and R1S.
  - General photos in the dropdown: Photos that aren't tied to a specific item make the dropdown more engaging. When: When the menu drops down and would otherwise be only text.
  - Recommendation: The source says more websites should show images in navigation, citing Rivian as doing it best.

### Process

1. Draw the accents: Get out the pencil tool and circle and underline some things over text, with flashes in the background if wanted; the example shown also adds arrows.
2. Keep the base text crisp: Set the rest of the text in bold, clean-cut type so the loose, hand-drawn marks contrast with it [inferred].
3. Check the font license: Before using a font you found on another site, confirm its license allows your use.
