# 5 Trendy Animations to Steal for Your Next Web Design

## Summary

Kole Jain sorts website animation into five types (entrance, hover or click, scroll, looped and mouse) and shows one subtle example of each, how it is built, and other sites that do something similar. His main stance is that beginners go too big or flashy, which can slow a site down and overwhelm people, so every example is kept subtle enough to work on almost any site. The entrance example is a short preloader that slides up while the content and background beneath it also move; the hover example is a masked button whose text and a circle slide up; the scroll example is text that highlights as you scroll; the looped example is a slow icon tracing a semicircle; and the mouse example is a call-to-action that moves to the cursor. For a design system, it gives a vocabulary of web animation types, a restraint rule (subtle, short, slow), and the reminder that mouse effects need a fallback on tablet and mobile.

## Key Ideas

- Web animations can be grouped into five types: entrance, hover or click, scroll, looped and mouse.
- Beginner animations often go too big or flashy, which can slow the site and overwhelm people; subtle and classy works on almost any site.
- A preloader (entrance animation) adds a premium feel and buys time for heavy media, such as giant background videos (and, he guesses, Fabric's 3D effect), to load.
- A preloader feels more fluid when the content and background beneath it also move as it slides away.
- Preloaders must stay short because people are impatient and want to see the actual content.
- A complex-looking button hover is built with a masking container: the label slides up, and a circle and a new label slide up too.
- Changing a button's text and background color on hover is common and reads as cool but professional.
- Highlight-on-scroll text is simple to build: a two-color gradient with near-touching stops, masked by the text and moved by scroll position.
- Looped animations should be simple, minimal and slow; complicated loops distract and can annoy.
- Looping marquee text should move slowly enough to read.
- Mouse effects should be used sparingly; their best use is bringing a call-to-action to the cursor.
- Mouse effects do not work on tablet and mobile, so they need a backup plan there.
- How quickly a cursor-following element snaps to the mouse, or eases in, is a tunable value.

### Process

1. Pick the animation type: Decide whether the moment calls for an entrance, hover or click, scroll, looped or mouse animation, and keep it subtle.
2. Build the preloader reveal: Slide the preloader section up; while it moves, also move the elements beneath it and slightly move any background image or video. Keep it short.
3. Build the masked button hover: Wrap the button content in a container that masks it. On hover, slide the label up out of view and slide a circle and a new label up into view; scale the circle and reduce its radius so it becomes more of a rectangle.
4. Build highlight on scroll: Make a container with a gradient of two colors whose stops are almost stacked, use the text as a mask, and move the colored rectangle across based on scroll position. Set the edge straight or diagonal, and move multiple lines together or staggered.
5. Build a looped icon animation: Move the icon along a semicircle path and draw the line behind it; keep it minimal and slow-moving.
6. Build a mouse-follow effect: Track the mouse position and center a container with the content around it; tune the values so it snaps faster or eases in slower.
7. Add a touch fallback: Plan a backup for tablet and mobile, where mouse effects cannot be used.
8. Study other sites, then experiment: Look at sites with similar animations for inspiration, then start playing around with your own versions.
