# 7 UI/UX mistakes that SCREAM you’re a beginner

## Metadata

- Video ID: `AH_ugxmLeUM`
- Channel: Kole Jain
- Published: 2025-06-07T03:17:13Z
- URL: https://www.youtube.com/watch?v=AH_ugxmLeUM

## Summary

Kole Jain walks through seven beginner UI/UX mistakes, plus a bonus one on charts, by fixing a simple recipe app one mistake at a time instead of redesigning it from scratch. The mistakes are an unplanned user flow, overused effects (gradients and harsh drop shadows), cramped spacing, inconsistent components, weak or mismatched icons, redundant elements, and missing interactive feedback. For each, he shows a concrete fix: sketch the flow first, remove or soften gradients and shadows, align to column grids and use auto layout, give duplicate components one design and one small-component corner radius, use one icon library with labels or tooltips where icons are unclear, cut arrows and strokes that add clutter, and show press and loading states. For a design system, this is a practical review checklist and a set of defaults: fewer effects, more space, shared styles, variables and components, consistent icons, visible feedback, and charts that favour readability over looks.

## Key Ideas

- You can make a UI look polished by fixing specific mistakes one at a time, without starting from scratch.
- Planning the user flow, even as boxes sketched on paper, catches gaps such as a missing search bar or skip button before users feel them.
- The elements designers most often miss are navigation links, hidden states and dynamic interactions such as button hovers and micro interactions.
- Overusing shadows, glows and gradients makes a design feel cluttered and amateur; less visual noise is usually better.
- If a gradient is needed, keep it within one color (lighter and darker shades), but no gradient is usually cleaner.
- Soften drop shadows by changing the shadow color to a light gray and raising the blur, not just by lowering opacity, or remove them.
- Beginner layouts are usually too tight; column grids, more vertical spacing and auto layout fix most of it, and mobile needs more space than you think.
- Components that do the same job must look the same, and all smaller components should share one corner radius.
- Consistency comes from styles for colors, variables for measurements and components for UI elements.
- Good icons speed up browsing and bad or mismatched icons hurt a design; use one library so fill, line width and style match.
- Well-known icons can stand alone, but unclear ones need a tooltip; different icon styles can coexist only in visually separate areas with different jobs.
- Remove elements that add nothing, such as arrows where people can swipe and strokes that are not needed.
- Actions need visible feedback: a grayed-out pressed button, a loading wheel for long waits, and a sign showing where a saved item went.
- Charts are often over-designed; a plain chart with an axis carries more useful information than a decorative one.

### Process

1. Improve in place: Take the existing design and fix one mistake at a time until it looks polished, instead of starting from scratch.
2. Plan the user flow: Sketch the screens as boxes on paper and look for gaps such as a missing search or skip option, missing navigation links, hidden states and hover or micro interactions.
3. Cut effects: Remove multi-hue gradients (or keep one-color ones), and recolor harsh default shadows to light gray with more blur, or remove them.
4. Fix spacing: Set up column grids, align elements to them, increase vertical spacing in stacks, and rebuild cards and chips with auto layout with vertical trim off.
5. Make components consistent: Make duplicate components identical, give smaller components one corner radius, and use styles for colors, variables for measurements and components for UI elements.
6. Fix icons: Add icons where text slows browsing, take them from one library as SVG, and add tooltips to icons that aren't well known.
7. Remove redundant elements: Delete arrows people don't need and strokes that add nothing, dimming instead where contrast is a concern.
8. Add interactive feedback: Show a pressed or grayed-out state on tap, a loading wheel for long waits, and a sign of where a saved item went.
9. Check charts for readability: Make sure charts have an axis, bars whose ends are clear, and one bar per data point.
