# 20 Top Underrated Web Design Resources for 2025

## Metadata

- Video ID: `eeN7yUcIWbw`

## Summary

Kole Jain walks through 20 web design resources he considers underrated for 2025, most of them free or mostly free. They cover ready-made UI elements (Uiverse, the Relume Figma kit), logos (Logo System, Logoipsum), animation (Phase), font pairing and display fonts (Fontjoy and a small display-font site), inspiration galleries (trending.design, Design Spells for micro-interactions, Unsectioned for page sections), imagery (Burst stock photos, Durves, Endless Tools 3D, Isocons isometric icons, Photo Gradient mesh gradients, Handy Arrows) and learning or career sources (UX of AI, Design Sphere podcasts, Wall of Portfolios). The video teaches no design method; its value for a design system is a list of where to find inspiration, placeholders and assets, plus a few stated reasons, such as beginners pairing fonts badly, Figma falling short for mesh gradients and for drawing arrows, and layout variety mattering. The picks are the presenter's opinions from January 2025, so availability and pricing may have changed.

## Key Ideas

- Uiverse offers buttons, animations and elements that can be pasted straight into Figma with a Copy to Figma button, which helps when a Figma file is still empty.
- Beginner designers tend to pair fonts badly, so a generator like Fontjoy can suggest a pairing with one button.
- Phase is presented as an easier way to animate Figma designs than Figma plugins or After Effects, with an editor very similar to Figma.
- Figma cannot produce everything a dedicated mesh-gradient tool like Photo Gradient can, so the source suggests using such a tool instead of switching to Photoshop.
- Variety in layout matters, and Unsectioned makes it easier by splitting real websites into searchable sections.
- Micro-interactions are a niche subject, so Design Spells curates the best ones from a ton of brands, including million- and billion-dollar companies.
- Logo libraries (Logo System, Logoipsum) help designers who are weak at logos, giving them many logos to scroll through.
- Burst, Shopify's free stock photo site, is smaller than Pexels but probably better organized, and the source argues you can never have too many stock photo sources.
- Isocons offers isometric icons that can be switched between rounded and sharp and given a thicker or thinner stroke.
- Relume's Figma kit is a very large community file (about 54 pages) that can be found in Figma without signing up to Relume.
- Figma's pencil tool is limited for arrows, so a dedicated arrow library such as Handy Arrows gives more variety.
- Seeing a designer's experience and location next to their portfolio (Wall of Portfolios) puts the work in perspective and discourages unfair self-comparison.
- Because most designers will eventually work with or near AI, studying UX of AI helps build a feel for it.
- 3D is often called the next big thing, and Endless Tools offers customizable 3D resources in case it is, though some are limited.
- Display fonts are something the presenter is always short of, which makes a small display-font site one of his favorite resources on the list.

### Process

1. Paste a ready-made element from Uiverse: Find an element you like, scroll past the code and click Copy to Figma.
2. Collect and tune isometric icons in Isocons: Choose rounded or sharp and the stroke thickness, click Add to folder, then view and customize them together in the folder at the top.
3. Get the Relume Figma kit without signing up: Search for it in the Figma Community, since it is a community file.
4. Get a new color set in Photo Gradient: If you don't like the current colors, refresh the page to get a new color guide.
