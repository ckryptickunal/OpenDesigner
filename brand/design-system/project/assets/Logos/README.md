# Logos

The mark is four tiles going from a square to a circle; the circle is the decision. The lockup is the mark plus "OpenDesigner" in Hanken Grotesk Medium, outlined (no font needed).

- `lockup-light.svg`, `mark-light.svg`: ink `#222428`, circle cobalt `#2338ff`. On the Light theme.
- `lockup-dark.svg`, `mark-dark.svg`: ink `#e6e9ee`, circle `#517cff`. On the Dark theme.
- `lockup-cobalt.svg`, `mark-cobalt.svg`: white, circle `#141517`. On the Cobalt theme.
- `lockup-light-mono.svg`, `lockup-dark-mono.svg`: one ink. Use them when the screen already spends its one accent elsewhere (a highlight box, a primary button).

Clear space: half the mark's width on every side. Smallest lockup 24 px tall; smallest mark 16 px.
