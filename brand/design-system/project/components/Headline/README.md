# Headline

The one highlighted phrase in a headline, done one of three ways: a fill box (`highlight`, strongest), weight 650 (default) or `accent-text` (quietest). Use one method once per screen, and only after deciding where the eye should land first.

- The consumer provides the headline text and which phrase to mark.
- Fill box: keep the phrase on one line and the headline's line height at least 1.08, and nothing else on the screen in cobalt.
- Never an italic serif word, never two methods together.
