# Names used in the showcase

Every invented person, company, brand, product, place and title in `brand/showcase/*/*/index.html`, one line per name, so a new piece can pick a name nobody else uses. This file was built on 2026-10-14 from the text of all 78 pages, including script data. `mockups/10-multi-device/desktop.html` is included because it is part of that mockup. Real places (Frankfurt, Wichita), real products and UI words are left out.

**Rule:** a name appears in one piece only. The exception is a mockup that shows another piece's product, for example `mockups/09` showing Quoin or `mockups/10` showing Quillon. Those reuse that piece's names on purpose and are listed with both pieces. Before you use a new name:
1. Search this file for the name and for its distinctive words. "Calder" also catches "Calder Inn" and "41 Calder Street".
2. Check for names one letter apart, like Ferrow and Ferrule.
3. Search the web for any new brand name in the same field.
4. Add the name here.
