## F-007 · 2026-10-14 · confusing
preflight.py M8 says web text must be 12px or more, but the engine's own type scale for this system has an 11px caption step (font-size-11, text-body-sm). A page that uses the engine's caption token passes preflight only because preflight reads px literals, not tokens. One of the two should change: raise the caption floor to 12px for web, or let M8 accept the engine's caption step.
