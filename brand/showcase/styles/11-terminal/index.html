NAME

A SQL database you can branch, diff and merge.

coppice is an embedded database in one 4 MB binary. Branches are copy-on-write, so a 2.1 GB database branches in 41 ms and keeps only the pages you change.

SYNOPSIS
coppice branch create name [--from branch]
coppice sql branch [-c query]
coppice diff a..b
coppice merge branch [--dry-run]
INSTALL
$ curl -fsSLO https://coppicedb.example/install.sh && sh install.sh
