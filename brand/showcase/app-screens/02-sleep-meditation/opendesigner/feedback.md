## F-002 · 2026-10-14 · bug · area typography
Instrument Serif has one weight (400), but the display styles get font.weight.heading 600 and display 700, so text.headline-* and text.display-* ask the browser for a faux bold. The engine should read the face's available weights or let the person set heading weight per face.
