# Feedback

Gaps, bugs, confusing steps and ideas found while using OpenDesigner. Each entry has a ready-to-file issue link. Nothing is posted unless you open the link and submit it yourself.

## F-001 · 2026-10-14 · bug
sketch --delegated all rewrites an explicit --brand hex to a white-text shade: #E8946A (apricot, meant to carry dark text on a dark player) became #AF6037 brown; #F04A1A became #D93900. The brief's recipe uses --delegated all, so a chosen brand color is silently lost from state.json. When --brand is given, keep the hex and pick a dark on-color instead (fixed by: set raw.brandColor '"#E8946A"' --set-by chosen).

[File this as an issue](https://github.com/ckryptickunal/OpenDesigner/issues/new?title=%5Bbug%5D%20sketch%20--delegated%20all%20rewrites%20an%20explicit%20--brand%20hex%20to%20a%20white-tex...&body=%2A%2AKind%3A%2A%2A%20bug%0A%0A%2A%2AWhat%20happened%20or%20what%20is%20missing%3A%2A%2A%0Asketch%20--delegated%20all%20rewrites%20an%20explicit%20--brand%20hex%20to%20a%20white-text%20shade%3A%20%23E8946A%20%28apricot%2C%20meant%20to%20carry%20dark%20text%20on%20a%20dark%20player%29%20became%20%23AF6037%20brown%3B%20%23F04A1A%20became%20%23D93900.%20The%20brief%27s%20recipe%20uses%20--delegated%20all%2C%20so%20a%20chosen%20brand%20color%20is%20silently%20lost%20from%20state.json.%20When%20--brand%20is%20given%2C%20keep%20the%20hex%20and%20pick%20a%20dark%20on-color%20instead%20%28fixed%20by%3A%20set%20raw.brandColor%20%27%22%23E8946A%22%27%20--set-by%20chosen%29.%0A%0A%2A%2AEngine%3A%2A%2A%201.0.0%20%28Python%203.10%29%0A%0A_Filed%20from%20%60engine.py%20feedback%60.%20Please%20remove%20anything%20private%20before%20submitting._&labels=bug%2Cfrom-engine)

## F-002 · 2026-10-14 · gap
OPEN_FONTS misses common OFL Google faces (Fraunces, Fredoka, Instrument Serif, Atkinson Hyperlegible Next and Mono): validate warns 'no recorded app licence' until raw.fontLicence is set by hand. The engine also sets weights the face lacks: Instrument Serif (400 only) gets heading 650 and display 750; Fredoka (300-700) gets 750 and 850, so browsers fake the bold.

## F-006 · 2026-10-15 · bug
On an iOS-only system, --ds-size-target-min drops to 24px under @media (pointer: fine). Headless renderers (and iPad with a trackpad) report a fine pointer, so a phone screen built from the token rendered 24 pt chapter rows and buttons. For platforms ios/android the touch minimum should not have a fine-pointer override, or the override should be opt-in.
