## F-003 · 2026-10-18 · gap
An iOS system had no --ds-font-size-22 (Title 2), so a CSS font shorthand using it was invalid and the heading silently fell back to the inherited 17 px. Nothing warned: validate and preflight both passed. The engine should emit every Dynamic Type role size for the chosen platform, and review or preflight should flag var(--ds-*) references that are not defined.
