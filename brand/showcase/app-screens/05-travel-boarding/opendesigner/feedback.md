## F-001 · 2026-10-14 · gap · area typography, question Q-type-10
No Apple HIG (Dynamic Type) named scale. Q-type-10 'named' only records a rule; the CSS tokens stay on the ratio formula (body.sm 14, title 21/27, headline 33) while the Swift export maps the same styles to Dynamic Type (.subheadline 15, .title2 22, .largeTitle 34), so CSS and Swift disagree. To get HIG sizes in CSS I had to add 8 font.size steps and override 11 text styles one by one with full typography JSON (set text.title.lg '{...}'), per system.

[File this as an issue](https://github.com/ckryptickunal/OpenDesigner/issues/new?title=%5Bgap%5D%5Btypography%5D%20No%20Apple%20HIG%20%28Dynamic%20Type%29%20named%20scale.%20Q-type-10%20%27named%27%20only%20record...&body=%2A%2AKind%3A%2A%2A%20gap%0A%0A%2A%2AWhere%3A%2A%2A%20area%20typography%2C%20question%20Q-type-10%0A%0A%2A%2AWhat%20happened%20or%20what%20is%20missing%3A%2A%2A%0ANo%20Apple%20HIG%20%28Dynamic%20Type%29%20named%20scale.%20Q-type-10%20%27named%27%20only%20records%20a%20rule%3B%20the%20CSS%20tokens%20stay%20on%20the%20ratio%20formula%20%28body.sm%2014%2C%20title%2021/27%2C%20headline%2033%29%20while%20the%20Swift%20export%20maps%20the%20same%20styles%20to%20Dynamic%20Type%20%28.subheadline%2015%2C%20.title2%2022%2C%20.largeTitle%2034%29%2C%20so%20CSS%20and%20Swift%20disagree.%20To%20get%20HIG%20sizes%20in%20CSS%20I%20had%20to%20add%208%20font.size%20steps%20and%20override%2011%20text%20styles%20one%20by%20one%20with%20full%20typography%20JSON%20%28set%20text.title.lg%20%27%7B...%7D%27%29%2C%20per%20system.%0A%0A%2A%2AEngine%3A%2A%2A%201.0.0%20%28Python%203.10%29%0A%0A_Filed%20from%20%60engine.py%20feedback%60.%20Please%20remove%20anything%20private%20before%20submitting._&labels=gap%2Cfrom-engine)

## F-002 · 2026-10-14 · bug · area typography, question Q-type-09
After hand-tuning, validate warns '14 text sizes; 8 to 10 is the usual range' because the formula steps stay in the primitives even when no style uses them, and there is no way to remove them (set font.size.21 null is a no-op). Overriding an existing step (set font.size.14 15) keeps the token name font-size-14 with a 15px value, which is misleading.

## F-003 · 2026-10-14 · confusing · area typography
set text.body.sm.fontSize ... is refused ('not a token path'); only the whole typography object can be overridden. A per-property override (fontSize, fontWeight) would make HIG or Material alignment a one-liner.
