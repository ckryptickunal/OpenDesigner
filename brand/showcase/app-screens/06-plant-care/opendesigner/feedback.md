## F-001 · 2026-10-14 · bug
preflight.py html is blind to token-based pages: it reads only px font sizes, so rem sizes from tokens.css give 'font sizes in px: []' (no small-text check at all), and every Google Fonts <link> face is an M9 error because only local @font-face counts. The showcase brief allows Google Fonts links.

## F-003 · 2026-10-14 · idea
opendesigner-illustrate recolor maps each source color to one token, so a line drawing whose single white fill covers both leaves and pot cannot become green leaves and a clay pot. A region option (recolor a polygon or bbox) would avoid the CSS multiply-clip workaround used here.

## F-004 · 2026-10-14 · gap
The Warmth dial has no effect once raw.neutralBase is set (neutral hue and chroma come only from the base hex): warmth 82, 60 and 45 gave identical neutral ramps, and nothing warns. A warm cream base (#E8DCC6) also turns secondary text brown (#5f5645), which the owner's color rule forbids. Say which input wins, and cap neutral chroma for text steps.
