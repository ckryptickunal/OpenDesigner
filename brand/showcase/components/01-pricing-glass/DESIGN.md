**Intent.** Body text is 16px; sizes follow `round(16 x 1.333^n)` for n from -2 to 6, reaching about 5.5x body (marketing surfaces in scope). Sizes: 12, 16, 21, 28, 38, 51, 67, 90px.

- Text face: Geist, system-ui, -apple-system, Segoe UI, Roboto, Helvetica Neue, Arial, sans-serif. Licence status (hook H-type): **pending**.
- Licence by platform: text: Geist (open licence or system font: web, apps and self-hosting); display: Instrument Serif: licensed for nothing recorded; not recorded for web, apps, self-hosting.
- On iOS the Swift file uses Dynamic Type text styles (body 17 pt), so text follows the person's text size setting; Compose uses sp, which follows the Android font scale.
- Weights: body 400, label 500, heading 650, display 750 (two or three distinct weights per view).
- Emphasized variants (Expression 85, on from 67): 11 styles under `text.emphasized.*`, the same size one weight heavier, for the selected item, key actions and headlines (DC-L02-11).
- Line heights snap to a 4px grid: 1.5 up to 17px, 1.4 to 26px, 1.25 to 44px, 1.12 above.
- Letter spacing: +0.02em at 11-12px, -0.01em from 32px, -0.02em from 48px.
- Text scaling: CSS sizes are rem, line heights unitless, so text scales to 200% (WCAG 1.4.4); containers must grow with it.
- Scripts: Latin only; add scripts in raw.scripts to get per-script line heights (DC-L02-25).

## Do's and Don'ts
