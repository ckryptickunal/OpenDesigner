# Feedback

Gaps, bugs, confusing steps and ideas found while using OpenDesigner. Each entry has a ready-to-file issue link. Nothing is posted unless you open the link and submit it yourself.

## F-001 · 2026-10-14 · bug · area color
Secondary colours are not kept as given: raw.secondaryColors ['#7E9475'] (a dried-herb sage) became accent2 step 9 #6c9c57, a bright grass green, because secondaries are lifted to the brand's chroma (max(peak, chroma)). There is also no seed token for a secondary colour like color.brand.seed. Keep secondaries exact when flags.brandExact is on, and emit color.accent2.seed.

## F-002 · 2026-10-14 · gap · area color
No illustration palette. The accent ramp is built for UI contrast steps: for a terracotta brand, light steps 2-7 drift salmon pink (#f9e8e2 to #f2bea9) and step 7 to 8 jumps from #f2bea9 to #b6775d, so there is no mid-tone clay for art. And art bound to UI roles (surface.base, text.primary) inverts in dark mode (white petals turned black). opendesigner-paint's brief already computes palette families; emitting them as theme-independent tokens (color.art.*) would serve code art and illustrations too.

[File this as an issue](https://github.com/ckryptickunal/OpenDesigner/issues/new?title=%5Bgap%5D%5Bcolor%5D%20No%20illustration%20palette.%20The%20accent%20ramp%20is%20built%20for%20UI%20contrast%20step...&body=%2A%2AKind%3A%2A%2A%20gap%0A%0A%2A%2AWhere%3A%2A%2A%20area%20color%0A%0A%2A%2AWhat%20happened%20or%20what%20is%20missing%3A%2A%2A%0ANo%20illustration%20palette.%20The%20accent%20ramp%20is%20built%20for%20UI%20contrast%20steps%3A%20for%20a%20terracotta%20brand%2C%20light%20steps%202-7%20drift%20salmon%20pink%20%28%23f9e8e2%20to%20%23f2bea9%29%20and%20step%207%20to%208%20jumps%20from%20%23f2bea9%20to%20%23b6775d%2C%20so%20there%20is%20no%20mid-tone%20clay%20for%20art.%20And%20art%20bound%20to%20UI%20roles%20%28surface.base%2C%20text.primary%29%20inverts%20in%20dark%20mode%20%28white%20petals%20turned%20black%29.%20opendesigner-paint%27s%20brief%20already%20computes%20palette%20families%3B%20emitting%20them%20as%20theme-independent%20tokens%20%28color.art.%2A%29%20would%20serve%20code%20art%20and%20illustrations%20too.%0A%0A%2A%2AEngine%3A%2A%2A%201.0.0%20%28Python%203.10%29%0A%0A_Filed%20from%20%60engine.py%20feedback%60.%20Please%20remove%20anything%20private%20before%20submitting._&labels=gap%2Cfrom-engine)

## F-004 · 2026-10-14 · gap · area paint
opendesigner-paint can only produce a brief without installs: painting needs npm install and Playwright Chromium per film project, which an agent must not run without the person's yes. An agent running unattended (or a subagent) cannot paint a still. A no-install still path (a single HTML page with p5 from a pinned CDN, or a canvas-only style) would make the skill usable for heroes.
