## F-001 · 2026-10-14 · bug · area color
With --delegated all, sketch replaced the given luminous aqua #46E0D3 with #00837b (a dark teal that carries white text). For a dark UI the right move is dark text on the bright aqua, which the engine already does (text.on-action = neutral dark 1). The shade check should not assume white text, and should not rewrite a hex the person gave.

## F-003 · 2026-10-14 · gap · area elevation
raw.darkBase black collapses the dark surface ladder: surface.base #000000, raised #010101, overlay #050608, so raised panels cannot be told apart from the page. Depth 85 in dark mode only adds black drop shadows, which are invisible on black. Dark systems need depth expressed as light: lifted surface steps, a rim highlight token and glow tokens (color + blur) for the accent.

[File this as an issue](https://github.com/ckryptickunal/OpenDesigner/issues/new?title=%5Bgap%5D%5Belevation%5D%20raw.darkBase%20black%20collapses%20the%20dark%20surface%20ladder%3A%20surface.base%20%2300...&body=%2A%2AKind%3A%2A%2A%20gap%0A%0A%2A%2AWhere%3A%2A%2A%20area%20elevation%0A%0A%2A%2AWhat%20happened%20or%20what%20is%20missing%3A%2A%2A%0Araw.darkBase%20black%20collapses%20the%20dark%20surface%20ladder%3A%20surface.base%20%23000000%2C%20raised%20%23010101%2C%20overlay%20%23050608%2C%20so%20raised%20panels%20cannot%20be%20told%20apart%20from%20the%20page.%20Depth%2085%20in%20dark%20mode%20only%20adds%20black%20drop%20shadows%2C%20which%20are%20invisible%20on%20black.%20Dark%20systems%20need%20depth%20expressed%20as%20light%3A%20lifted%20surface%20steps%2C%20a%20rim%20highlight%20token%20and%20glow%20tokens%20%28color%20%2B%20blur%29%20for%20the%20accent.%0A%0A%2A%2AEngine%3A%2A%2A%201.0.0%20%28Python%203.10%29%0A%0A_Filed%20from%20%60engine.py%20feedback%60.%20Please%20remove%20anything%20private%20before%20submitting._&labels=gap%2Cfrom-engine)
