## F-004 · 2026-10-14 · gap
The generated system works against the owner's type rules (two fonts at most, about six sizes with HIG/Material role names). Every build emits three face roles (text, display, mono) and eight font-size steps (12-90), with 14+ named styles (body/label/code/title/headline sm-md-lg, display). There is no 'caption' role. A marketing surface should get a lean role set: display, headline, title, body, label, caption, with a two-family default.

## F-005 · 2026-10-14 · bug
preflight.py html only counts font sizes written in px. Token sizes are rem (var(--ds-font-size-*) or the text-style shorthands), so on a token-built page M6 (too many sizes, sizes within 10%) and M8 (too small) see nothing: 'font sizes in px: []'. It should resolve the token rem values.
