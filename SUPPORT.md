# Getting help

| You need | Go to |
|---|---|
| A question about using OpenDesigner, design systems or the research | [GitHub Discussions](https://github.com/ckryptickunal/OpenDesigner/discussions), category **Q&A** |
| To share a design system you made with it | Discussions, category **Show and tell** |
| An idea for the interview, a building block or a new AI host | Discussions, category **Ideas**, or the matching issue form |
| To report a bug or a wrong research value | [Open an issue](https://github.com/ckryptickunal/OpenDesigner/issues/new/choose) and pick the form that fits |
| To report a security problem or a conduct issue | Private reporting, as described in [SECURITY.md](SECURITY.md) |

Before asking, these usually answer it:

- [docs/FAQ.md](docs/FAQ.md): the questions people ask most
- [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md): the process, the building blocks and the dials
- [docs/RESEARCH.md](docs/RESEARCH.md): where the evidence for each recommendation lives

OpenDesigner is maintained by volunteers. There is no paid support. If your AI tool gives a strange answer, include the tool, the model, how you loaded OpenDesigner and the last few turns of the conversation; that makes the problem reproducible.
