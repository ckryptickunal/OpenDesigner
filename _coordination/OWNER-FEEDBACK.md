Mistakes made or caught in this session, and the rule that now prevents each:

1. A bare `git commit` swept in a file rename another session had staged. The commit was redone with explicit paths. Rule: `git commit -- <paths>` in a shared checkout (`PROTOCOL.md` section 4).
2. In zsh, a path list in `$paths` was not split into words, so `git add` failed. Rule: `${=paths}`.
3. A generated copy (`chatgpt-project/knowledge/05-engine.py`) went stale after a last engine edit. The working-copy checks passed because other files hid it; a clean checkout caught it. Rule: run `build_data.py` after the last edit, and check a clean `git worktree` of what you commit.
4. The first taste card sat between a section's plain sentence and its folded detail, which broke the three-voice layout. An existing test caught it, and the card moved after the fold instead of the test being weakened. Rule: when a contract test fails, change the design, not the test.
5. A showcase page offered a copy button for an install command piped from an unregistered domain into a shell. Anyone could have bought the domain. `scan_pr.py` blocked it. Rule: invented brands use RFC 2606 `.example` domains, and shown commands download before they run (`brand/showcase/BRIEF.md`).
6. A rule that quoted the blocked pattern was itself blocked by the scanner. Rule: describe a blocked pattern in words.
7. `yt-dlp` needs a login for Instagram, and `timeout` does not exist on macOS. The working path for login-walled videos is in `learn/README.md`.

**Lessons the agent learned** (each is now a rule in the files named):
1. A layout checked at one width is not checked. Measure every row's centre, edges, top and height from 320 to 1920 px (`site/check_layout.py`).
2. A stagger the builder meant as dynamic reads as an error to the owner. Keep siblings on one top edge unless asked for a cascade (preflight M36).
3. Invented names that "feel invented" were real five times (Ledger, Orrery, Chorus, Pomelo, Vigil). Web-search every name before it is rendered (preflight M38).
4. A screenshot embedded in a page goes stale: the overview image still showed house standards v2 and old feel words. Re-capture it with the brand font loaded after each brand change (`site/README.md`).
5. A scroll reveal that hides content breaks full-page screenshots and reduced motion. Reveal only content below the fold, and hide nothing when motion is reduced (`site/static/site.js`).
6. Docs drifted from the repo while the work moved fast: 352 Decision Cards (now 543), 119 engine tests (now 157), five public skills (now eight), a "rewritten" brand color (now kept exact), shadcn/ui variables the exports do not have. Rule: after a change, search the docs for its counts and claims (preflight 25), and keep shipped and planned apart (`CONTRIBUTING.md` ground rule 8). The 2026-10-15 claims audit fixed these in `site/docs/`, `docs/`, `AGENTS.md` and `CONTRIBUTING.md`.
7. Name checks were by hand, and two pieces already share near names (Halde and Halden). Rule: `brand/tools/check_names.py` runs before a page with invented names ships (`ROUND3-BRIEF.md` rule 5, preflight M38).
8. A reviewer who knows which side is ours scores it kindly: components and an app screen at 4 out of 5 were "rubbish" to the owner. Compare blind, with a shipped screen, sides in random order (`making.md` section 5).
9. Splitting a headline into letters for an animation drops the font's kerning, and measuring before the font loads makes it worse. Load the real font, give each letter pair its kerning back, and check that the last frame matches the plain text (`site/static/site.js`).
10. An eval finds faults in the test before the product. The first agent run scored two cases 0 because the sandbox blocked copying their fixtures, and two rubrics were unfair. Read every failing grader's explanation before believing a number, and keep a first run on record as not comparable (`evals/agent/results/2026-10-20-first-run.json`).
11. A real fault found by an eval is fixed and measured the same way: the same case and graders on the old skills and the new (`agent_evals.py --ref`). The brand-color rule went from 1 of 3 runs to 3 of 3; four checker bugs were found by planted-defect pages and fixed (review precision 87% to 100%).
