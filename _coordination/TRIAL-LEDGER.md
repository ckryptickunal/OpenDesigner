# Trial ledger: what people had to ask for by hand

Every correction a person had to type during a demo trial (`docs/DEMO-TRIALS.md`) is logged here, with the repo fix that should make it unnecessary next time. The goal is a column of zeros: **no correction should be needed in two trials.** A correction that shows up again after its fix shipped means the fix didn't work. Reopen it, and write an agent eval if there isn't one.

How to add a trial:
1. `python3 tools/trial_messages.py <trial folder> --out ~/od-trials/_ledger/<trial>-messages.md` (stays local).
2. Split each message into separate corrections. Add new ones as rows, and raise "Times" on ones already here.
3. For each new row, make the fix: a rule where agents read it at the right step, a check or review case, and an eval when it can be graded. Then fill "Fix" and "Status".

Kinds: **see** (had to ask to see the work), **quality** (looked cheap, AI-made or bland), **fit** (wrong for the users or industry), **data** (dashboards and numbers), **craft** (alignment, consistency, details), **process** (how the agent worked), **setup** (install and tools).
