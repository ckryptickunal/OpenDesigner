# Translations

Translations of [`README.md`](../../README.md) and [`docs/FAQ.md`](../FAQ.md) live here, one folder per language code (ISO 639-1).

| Language | Code | README | FAQ |
| --- | --- | --- | --- |
| Español | `es` | [README](es/README.md) | [FAQ](es/FAQ.md) |

## Adding a language

1. Copy `README.md` and `docs/FAQ.md` into `docs/i18n/<code>/`.
2. Translate the prose. Keep code blocks, commands and image paths unchanged.
3. Point every other link at the English file, e.g. `../../CONTRIBUTING.md`.
4. Ask a second native speaker to review, then open a PR mentioning them.
