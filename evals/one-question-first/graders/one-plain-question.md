PASS if the reply asks the person for one thing only (a single question, which may offer a few options or examples), in plain words a non-designer understands, and does not write UI code yet. When the question has options, it recommends one with a short reason; an open question such as "what is your app?" may give examples instead. FAIL if it asks several separate questions at once, uses unexplained design jargon, starts building screens or styles, or invents details about the product (its name, audience or brand color).
