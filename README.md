# Design-System research

Research base for a **design-system builder**: a product that helps people create their own design system from building blocks.

## Where things are
| Path | What it holds |
|---|---|
| `_coordination/` | How agents and sessions collaborate: `BOARD.md` (who owns which lane), `PROTOCOL.md`, `SCHEMA.md` (source tiers, Decision Card format), `SESSION_PROMPT.md` (prompts for extra sessions) |
| `sources/` | `COMMUNITY-SIGNAL.md` (what practitioners say now, from /last30days), `SOURCE-REGISTRY.md` (every candidate source with its tier and verdict), raw last30days runs |
| `research/` | One file per lane (L01 color to L11 process), written as Decision Cards |
| `benchmarks/` | Side-by-side teardown of about 22 famous design systems |
| `traces/` | Append-only log of every source each lane opened, including rejected ones |
| `synthesis/` | The combined outputs: ontology, designer questionnaire, decision graph, builder spec, verification report |
